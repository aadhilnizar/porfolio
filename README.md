# Aadhil N J — Portfolio

A warm, timeless personal portfolio built with **Next.js 15** (App Router),
`next/font` (Fraunces + Inter), and hand-crafted CSS. No template, no UI kit.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for production

```bash
npm run build
npm start
```

## Editing content

All text lives in one place: [`app/data.ts`](app/data.ts).
Update your role, experience, projects, skills, and links there — the
page rebuilds itself from that data.

## Add your resume for download

Place your PDF in `/public` named `Aadhil_NJ_Resume.pdf`.
(See `public/resume-README.txt`.)

## Deploy

Push to GitHub and import into **Vercel** — zero config. Or `netlify deploy`.
